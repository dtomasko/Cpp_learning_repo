# Exercise LV00: Variables, Data Types & Random Numbers

## Task 0.1
Declare an integer, a float, a double, a char, and a bool. Initialize them with appropriate values and print them.

## Task 0.2
Ask the user to enter an integer and a double. Store them in variables and print their sum, difference, product, and quotient.

## Task 0.3
Write a program that generates a random integer between 1 and 100 and prints it. Use `rand()` and `srand(time(0))`.

## Task 0.4
Generate a random floating-point numbers between 0.0 and 1.0 using `rand()` and print them with 3 decimal places.

## Task 0.5
Declare a constant double `PI` with value 3.14159. Calculate the area of a circle given radius entered by the user.

## Task 0.6
Write a program that demonstrates integer overflow by adding 1 to the maximum value of an `int` (use `INT_MAX` from `<climits>`).

## Task 0.7
Create variables of type `short`, `int`, `long`, `long long`, and print their sizes using `sizeof`.

## Task 0.8
Write a program that swaps two integer variables without using a third variable (using arithmetic or XOR).

## Task 0.9
Generate a random character (printable ASCII) and print it along with its integer value.

## Task 0.10
Write a program that converts Celsius to Fahrenheit and vice versa. Use `double` variables.
